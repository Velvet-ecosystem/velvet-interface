
An equivalent absolute-path form is:


Quote the editable requirement when it contains `[qt]`. An unquoted path may be interpreted by the shell rather than passed intact to `pip`.

## Runtime lifecycle contract

Runtime expects:

```python
from velvet_interface.lifecycle import InterfaceLifecycle
```

The lifecycle contract is intentionally narrow:

- zero-argument construction
- idempotent `on_runtime_start()`
- read-only `runtime_started` state
- no Runtime reference storage
- no route opening
- no publishing
- no authorization
- no execution
- no shell access
- no CAN or hardware control

Presence of the Interface package does not create authority.

## Founder window launch

The window consumes a saved Runtime snapshot:

```bash
cd ~/velvet/velvet-interface

/home/coyote/.pyenv/versions/3.10.20/bin/python3 \
  examples/runtime_boot_window.py \
  --snapshot ~/velvet/velvet-runtime/.velvet-dev/first-boot-snapshot.json
```

The snapshot must be regenerated by Runtime after package, identity, policy, or service changes. Interface displays the supplied evidence; it does not independently re-run Runtime diagnostics.

## Evidence rules

The Founder window must distinguish between:

- component absence
- missing state
- failed verification
- Runtime inactivity
- read-only readiness
- physical-control disablement

A green visual state is valid only when backed by trusted snapshot fields. Interface must not turn a stale or synthetic state into a claim that Runtime or hardware acted.

## Independence check

Closing the Founder window must not:

- stop Runtime
- change Court readiness
- alter continuity state
- enable or disable routes
- change physical authority

Interface is a presentation client of Runtime state, not Runtime itself.

## Hardware milestone

Physical UP² validation is complete for the minimal Founder boot-status experience.

The next hardware milestone is unattended presentation startup:

```text
power applied
  -> Runtime starts and verifies
  -> a fresh boot snapshot is produced
  -> Founder window launches in the graphical session
  -> Waiting for Mister
```

That startup path must remain fail-closed. It must not silently generate production identity, hide diagnostic failure, or enable physical control.
